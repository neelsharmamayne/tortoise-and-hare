# tortoise-and-hare

Two small static projects live here:

- **`/`** — *The Tortoise and the Hare*, a scroll-driven living storybook (`index.html`, `script.js`, `styles.css`).
- **`/gratitude/`** — *Three Good Things*, a private, self-hosted gratitude journal PWA. See [`gratitude/README.md`](gratitude/README.md) for hosting, Home Screen install, and reminders.
